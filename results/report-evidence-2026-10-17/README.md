## 引用规则

- 算法正确性写：**7 个变体指纹一致；默认和 MCU 两档 DTLCP 各 42 项，失败 0**。
- MCU 性能优先引用 F103 DWT 真机数据，不用主机数据代替 MCU 结论。
- 主机 cycles 只能在同一个文件、同一次运行内部求比值，不可拼接两次快照。
- CT 的安全结论引用 4096 个标量下点加、倍点、域乘次数极差均为 0；耗时只写
  “约 1.1 倍”，若写精确值必须同时注明具体快照。
- 本目录只收录实测或由实测派生的数据；功耗模型估算不收录，报告引用时必须标注为“模型估算”。
- RAM 的 6256 B 是扣除协议上下文、静态区与静态栈下界后的预算余量，
  尚未扣除中断、ABI 和应用缓冲，不是最终可用内存。

## 不应再使用的旧值

- 6 个算法变体、DTLCP 36 项。
- SM2 变基点乘相对 GmSSL 为 0.70 倍。
- “固定结构域约减尚未完成”或“仍需试商收尾”。
- 把 `30,080 B / 21,000 B` 的主机对象尺寸与 F103 `29,720 B` 固件尺寸放在同一列比较。
- 把 CT 的不同主机快照混成一张表。
