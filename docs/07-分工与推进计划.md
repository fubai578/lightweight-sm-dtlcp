## 1. 现状剖析（先说清楚为什么要这么排）

### 1.1 三个硬约束（决定顺序）

1. **工具链全空**：本机没有 `arm-none-eabi-gcc` / `openocd` / `pyocd`，**连 make 都没有**（只有 host gcc 8.1、python 3.13、MinGW 的 `size`/`objdump`）。
   → 第一件事；固件构建要给 `build.sh`（不依赖 make），与仓库既有风格一致。
2. **DTLCP 栈占用是头号风险**：`DTLCP_RECBUF=1600`，`dtlcp_hs.c` 多个握手函数**单帧**就有
   `payload[1600] + packet[1600] + body[600]` ≈ **3.8 KB 栈**；再加记录层上下文 3×1600 B ≈ 4.7 KB。
   F103C8T6 只有 20 KB RAM → **必须先测栈深，再定降档或复用方案**。
3. **报告口径不一致**：`docs/06` 写「Cortex-M4 裸机工程骨架」，实测将在 M3 上；且报告里
   「折叠约减在无硬件除法的 MCU 上更优」自标为**待验证假设** —— 而 F103 的 M3 **有** SDIV/UDIV 硬件除法，
   所以板上实测只能回答「M3 上的表现」，措辞必须按此收窄，不能顺势写成结论。

### 1.2 硬件 → 解锁的数据

| 硬件 | 能力 | 解锁什么 |
|---|---|---|
| F103C8T6（M3 @72 MHz / 64 KB Flash / 20 KB RAM） | DWT 周期计数；**无硬件 RNG** | 板上 cycles；Cortex-M3 的 size/栈；受限端裁剪实证 |
| DAPLink / ST-Link | SWD 烧录调试 | 「可移植嵌入式 C」真机验证 |
| CP2102 / CH340 | UART | KAT / cycles / 协议统计的**唯一出口** |
| INA226 | I²C，25 µA/LSB @0.1 Ω | **功耗：估算 → 实测**（`docs/04 §6` 整章） |
| W5500 | SPI + 硬件 TCP/IP（UDP socket），**免 LwIP** | **MCU 侧真跑 DTLCP over UDP** |
| 面包板 / 跳线 / 电池盒 | 可断开的供电通路 + 独立供电 | 功耗测量的**测量前提** |

### 1.3 软件侧本轮大多不动

`crypto/` 六变体与 `dtlcp/` 已全绿（只加板上数据）；`embedded/` 是主战场（补 F103 移植）；
`apps/bench`、`apps/demo` 复用其抽象（`dtlcp_io`、`bench` 逻辑），加板级入口即可。

## 3. 任务卡（T0–T7）

> 「占板」列是**硬件占用时长**，用于排班避免撞车；标 0 的任务只要电脑，任何时候都能做。

### T0 · 板级基线（**阻塞所有人，最先做**）
- **占板**：约 2 天（其中烧录调试约半天，其余是装工具链/写代码）
- **前置**：无
- **做**：
  1. 装 GNU Arm 工具链（xPack zip 解压即用，无需管理员）+ OpenOCD 或 pyOCD（**DAPLink 优先用 pyOCD**）；CMSIS F1 头（`STMicroelectronics/cmsis-device-f1`）落 `embedded/cmsis/`；
  2. 写 `embedded/build_f1.sh`（**不依赖 make**）；
  3. `stm32f103c8.ld`（FLASH 64 K / RAM 20 K）、`-mcpu=cortex-m3 -mthumb`（去 FPU）；
  4. `smc_port_f1.c`：DWT 周期计数保留；**RNG 钩子 → 确定性测试路径**（预留 ADC 噪声熵源接口）；看门狗 / 延时；
  5. GCC stdio：`_write()` → USART1（PA9/PA10，115200）；KAT 去 `sscanf`（省 Flash）；`-specs=nano.specs`。
- **验收**：`arm-none-eabi-size` 在 64 K/20 K 内 + **串口打印 KAT 全绿**（贴日志）
- **涉及**：`embedded/**`
- **兜底**：DAPLink 认不到 → 换 OpenOCD → 再不行用 **UART ISP**（F103 自带 bootloader，用 CP2102 就能烧）

### T1 · 板上 cycles 矩阵
- **占板**：半天（复用 T0 固件，改 `smc_config.h` 档位重烧 3–4 次）
- **前置**：T0
- **验收**：`docs/04` 新增「Cortex-M3 实测」表：SM2/SM3/SM4 × REF/OPT(/TINY/SMALL)，与 host 数据并排
- **顺带回答报告两个悬案**：① SM3 展开在 MCU 上是否有收益（host 0.86× 无收益）② 折叠约减在 M3 上的表现（注意 §1.1-3 的措辞边界）

### T2 · 内存 / 栈深 / 32 KB 链接证据
- **占板**：**0**（只要交叉编译器，不需烧录）
- **前置**：T0 的构建脚本能编译
- **做**：`size` + `-fstack-usage`；给 `scripts/stack_depth.py` 加 `--objdump` 选项以支持 `arm-none-eabi-objdump`（脚本已参数化，改动很小）；把 `FLASH LENGTH` 临时改 `32K` **链接一次**并留证
- **验收**：三份数据 + 可复现命令
- **涉及**：`embedded/**`、`scripts/stack_depth.py`

### T3 · 功耗实测（INA226）
- **占板**：1 天
- **前置**：T0（不依赖 T1/T2）
- **做**：INA226 I²C 驱动（PB6/PB7，100 kHz）；**差值法协议**（idle 基线与 run 窗口分开采、GPIO 做区间标记、上千次重复取均值）；**INA226 自身 330 µA 必须接在分流电阻之前**
- **验收**：`scripts/power_model.py` 顶部三个参数换成实测并重跑；出 µJ/op 表 → 改写 `docs/04 §6`
- **涉及**：`embedded/**`（驱动 + 测量程序）

### T4 · W5500 + DTLCP 真机端到端
- **占板**：2–3 天（最长的一项，尽早开工）
- **前置**：T0
- **做**：SPI 读写 W5500 socket 寄存器，把 `apps/demo/udp_io.h` 的 `send/recv` 抽象换成 W5500 实现（socket 缓冲配 2 KB 装得下 1600 B 记录）；板子做 sensor、PC 跑 `dtlcp_gateway`；跑通 FULL / RESUME / PSK(+0-RTT)；真机负向（重放/篡改/截断）
- **验收**：真机握手时延/线上字节表（对照 host 数值）+ 演示录屏 + `docs/02` 新增真机章节
- **涉及**：`apps/demo/w5500_*`、`embedded/**`（构建接入）

### T5 · 20 KB RAM 预算裁决
- **占板**：0（只改代码 + host 复测；复测栈深时用交叉编译）
- **前置**：T2 的栈深数据
- **做**：二选一或组合 —— `DTLCP_RECBUF` 降到 1024（仍容纳 FULL 握手 body ≈600 B），或让握手函数复用 ctx 缓冲、消掉 3.8 KB 单帧
- **验收**：RAM 预算表 + host 6 指纹与 42 项**仍全绿**
- **涉及**：`dtlcp/**`

### T6 · 域运算改造（**与硬件完全无关，随时可开工**）
- **占板**：0
- **前置**：无（这就是等待期该做的事）
- **做**：用一次性硬编码 Solinas 归约替换 `fe_reduce_fold` 的「多轮折叠 + 试商收尾 + 两次条件减」，目标 `fe_mul` 562 → 255–300 cycles，收掉对 GmSSL 的 **0.64× 落后项**
- **验收**：6 变体差分指纹**逐位一致** + `scripts/thirdparty_bench.sh` 交错复测（变基点乘转正 >1×）
- **涉及**：`crypto/**`

### T7 · 文档与材料定稿
- **占板**：0
- **前置**：T1/T3/T4 的数据齐
- **做**：按 §5 落点清单更新 `docs/04/06/02/03`；复赛材料（附件二/三）+ **匿名检查**（不得出现姓名/单位）
- **验收**：diff + 材料清单

## 7. 风险与预案

| 风险 | 预案 |
|---|---|
| 工具链 / OpenOCD 在 Windows 装不上或认不到 DAPLink | 先 pyOCD（对 DAPLink 支持最好）→ OpenOCD → **UART ISP 兜底** |
| 20 KB RAM 放不下 DTLCP + 驱动 | 依 T2 栈深：`RECBUF` 降 1024 / 握手复用 ctx 缓冲 / 关 SM2 ENC（已可裁） |
| 64 KB Flash 超预算 | `nano.specs` + 去 `sscanf`/浮点 `printf` + SM4 只留 CTR + 只留 OPT 档 |
| 无 RNG 使 TRNG 条款无法演示 | 决策 D1；否则 `docs/03` 明确「TRNG 由集成方落实」，实验室用确定性 nonce（§2.4 已允许） |
| 时间紧 | T4 降级为「单向遥测 + PC 网关」最小演示；**T1 cycles 与 T3 功耗是必保项**（报告已引用） |
