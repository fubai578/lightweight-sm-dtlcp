# 真实终端记录的安全拒绝演示（2026-11-24）

本轮不增加性能优化，不生成遥测或历史演示数据。
开发板 F103 + W5500 发送真实加密在线状态，C 网关捕获实际应用记录进行本地注入验证。

| 测试 | 操作 | 实际结果 |
|---|---|---|
| 篡改 | 翻转实际捕获记录 MAC 的一位 | dtlcp_rec_unprotect 返回 -5 / E_VERIFY |
| 重放 | 再次提交已接受的同一记录 | dtlcp_rec_unprotect 返回 -6 / E_REPLAY |

两次测试的接收状态均与测试前逐字节一致。协议函数执行真实 MAC 校验与防重放检查，页面不预设返回结果。
两次拒绝后，继续收到第 4–12 条正常业务，完整一轮 12 条状态、12 条 ACK，并通过板端 SWD 完成态确认。
各请求、实际 C 返回事件与后续消息序号见 real-board-events.json。

## 边界

注入位置是**网关本地生产记录层函数入口**，不是通过网线发送异常 UDP 报文；因此不声称完成外部网络攻击演练。
复用线上真实接收状态，测试返回失败或状态不符立即停止网关，不将记录副本交给业务或产生 ACK。
原始密文与密钥保留在 C 网关内存，不输出到网页或证据文件。
线上收发计数不包含本地副本；安全计数不冒充协议统计中的 replays_dropped。
客户端固件和密码核心本轮未改动。

## 录制

1. 运行 `python apps/dashboard/server.py`，打开本机网页。
2. 执行 `python scripts/security_demo.py`：复位实际开发板并在收发期间触发两种测试，检查后续通信。
3. 或运行普通 board_dashboard 脚本后手动点“篡改测试”“重放测试”。
4. 完成后测试窗口持续 60 秒。没有真实记录、服务断开、待返回或窗口结束时禁用按钮。
5. 可以暂停页面、全屏和导出公开事件；请求无返回时不计为通过。
