# 01 · 实现路径规划

> 选题：资源受限物联网终端轻量级国密算法优化与 DTLCP 国密改造实现（A1-33）
> 本文档是总工程路线图：交付物分解 → 总体架构 → 技术路线 → 测评方案 → 里程碑 → 风险对策。

## 1. 交付物分解（对照赛题要求）

| 赛题要求 | 交付物 | 落点 |
|---|---|---|
| ① SM2/SM3/SM4 轻量化裁剪与指令级优化 | 三算法各 **REF（基线）/OPT（优化）双内核** + 编译期裁剪开关；Flash/RAM/栈占用实测对比 | `crypto/`、`scripts/size_report.sh` |
| ② 基于标准 DTLCP 国密改造，UDP 低时延加密传输 | DTLCP 记录层 + 握手状态机 + 密钥调度 + 防重放；**原生套件 → 轻量国密套件**；握手 3-RTT→1.5-RTT，会话恢复 1-RTT，PSK 0-RTT | `dtlcp/`、`apps/demo_*` |
| ③ 算法实测、优化前后算力/功耗对比 | 基准程序（cycles/ns/Flash/RAM/栈）+ 功耗能量模型 + **优化前后对比报告** | `apps/bench/`、`docs/04` |
| ③ 可移植嵌入式 C 代码 | 无动态内存、无 libc 依赖的 C99 算法库 + 平台移植层 + Cortex-M4 裸机工程骨架 | `crypto/`、`embedded/` |
| ③ 固件安全改造规范 | 9 章规范文档（安全启动/密钥管理/TRNG/算法使用/侧信道/通信/升级/测试验收） | `docs/03` |

## 2. 总体架构

```
┌────────────────────────────────────────────────────────────┐
│  apps/        demo(传感终端+网关)  bench(基准)  tests(KAT/差分) │
├────────────────────────────────────────────────────────────┤
│  dtlcp/       握手状态机 ── 密钥调度(PRF-HMAC-SM3) ── 记录层     │
│               (FULL 1.5-RTT / RESUME 1-RTT / PSK 0-RTT)      │
│               记录保护：SM4-CBC-MtE（标准）/ SM4-CTR-EtM（轻量） │
├────────────────────────────────────────────────────────────┤
│  crypto/      SM2(签名/ECDH, ENC 可裁剪)  SM3  SM4  HMAC  DRBG  │
│               每算法 REF/OPT 内核，编译期二选一，API 完全一致     │
├────────────────────────────────────────────────────────────┤
│  embedded/    port(熵源/周期计数/看门狗/延时) + Cortex-M4 工程   │
└────────────────────────────────────────────────────────────┘
```

设计原则：
- **纯 C99、零动态内存、零 libc 依赖**（算法层仅 `stdint/stddef`），可直接编入裸机/RTOS 固件；
- **REF/OPT 双内核同一 API**：既是"优化前后"对比基准，又互为差分测试判据（同输入必同输出）；
- **编译期裁剪**：不参与的功能（SM2 公钥加密、SM4-ECB/CBC、会话恢复、双向认证）可整体裁掉，输出 Flash/RAM 差值表。

## 3. 技术路线

### 3.1 SM3（哈希）— 三档内核
| 内核 | 策略 | 目标 | 附加资源 |
|---|---|---|---|
| REF | 教科书式：W[68]+W'[64] 全展开数组、逐轮宏 | 性能基线 | 栈 528 B |
| **OPT=FAST** | **压缩函数全展开 + 消息扩展 2 路交织 + load/store 合并** | 最快 | 栈 528 B |
| TINY | 消息扩展滚动计算：16 字环形缓冲 + 4 字流水（W'[j-4]=W[j-4]^W[j]） | 最小栈 | **栈 64 B** |

### 3.2 SM4（分组密码）— 三档内核
| 内核 | 策略 | 常量表 | 轮函数 |
|---|---|---|---|
| REF | 逐字节 τ + 逐轮 L（严格按标准定义） | S-box 256 B | 循环 32 轮 |
| **OPT=FAST** | **T-table 合并 L∘τ（查表 4 次/轮）+ 8 轮展开 + 轮密钥预展开** | **4 KB** | 展开 |
| SMALL | τ 用字节 S-box、L 用移位异或原地展开，无 T 表 | **256 B** | 展开 2 轮一组 |

模式层：块接口 + CBC/CTR（CTR 为 DTLCP 轻量记录层服务）。

### 3.3 SM2（椭圆曲线）— 域算术 + 标量乘双优化
- **域算术**（Fp, p = 2²⁵⁶−2²²⁴−2⁹⁶+2⁶⁴−1）：
  - REF：schoolbook 乘法 + **逐位移位减模约减**（教科书大整数除法）；
  - OPT：schoolbook 乘法 + **Solinas 折叠快速模约减**（利用 2²⁵⁶ ≡ 2²²⁴+2⁹⁶−2⁶⁴+1 (mod p) 两轮折叠）；标量域 n 用轻量 Barrett/移位减（出现频次低）。
  - 求逆：Fermat a^(p−2) 平方乘（常量时间友好，代码小）。
- **标量乘 k·P**：
  - REF：二进制倍点-点加（MSB 优先）；
  - OPT：**4-bit 固定窗口**，15 点预计算表 + 混合坐标加法（mixed add, Z₂=1）；
  - CT 选项：全表扫描 + 常量时间选择（抗缓存时序/SPA，代价约 2×），按安全需求编译选择。
- **协议函数**：ZA 计算、SM2 签名/验签、ECDH 密钥协商（含公钥合法性检查：on-curve/无穷远拒绝）；SM2 公钥加密（P1C2C3）整体**可裁剪**（DTLCP 不需要）。
- 确定性 nonce：k 由 (d‖e‖SM3 DRBG) 派生（可测可复现）；规范文档要求生产环境接 TRNG。

### 3.4 DTLCP 国密改造（TLCP/GB-T 38636 的 UDP 适配）
1. **套件替换**（要求②的"替换原生密码套件"）：
   - 保留兼容：`ECDHE_SM4_CBC_SM3`（MAC-then-encrypt，向标准 TLCP 记录层兼容）；
   - 新增轻量：`L_SM2_SM4_CTR_SM3` / `L_PSK_SM4_CTR_SM3`（**Encrypt-then-MAC**，CTR 免 padding、免 IV 扩散等待，低时延优先）。
2. **握手精简**（3-RTT → 1.5/1/0-RTT）：
   - FULL：CH → (SH‖Cert‖SKE 合并 1 数据报) → (CKE‖CCS‖Finished 合并 1 数据报) → CCS‖Finished = **1.5-RTT**，仅 1 次 SM2 签名 + 1 次验签；
   - RESUME：会话 ID 恢复，全程 **0 次 SM2 运算**，1-RTT；
   - PSK：预共享密钥，**0-RTT 早期数据**（带重放风险声明与计数器窗口缓解）。
3. **UDP 语义**：epoch+48bit 序列号 + 64 位滑动窗口防重放；记录独立（无跨记录链式 IV），抗丢包重排；单记录 = 单数据报（无跨包重组状态，适合低内存终端）。
4. **紧凑证书**：v1 紧凑 SM2 证书（subject‖issuer‖65B 公钥‖r‖s），文档给出到 X.509 的映射约束。

### 3.5 测评方案（要求③）
- **正确性**：标准 KAT（GM/T 0004 / 0002 / GB/T 32918 附录向量）+ **OpenSSL 3.2 CLI 交叉验证** + REF/OPT 差分测试（≥10⁴ 随机向量）+ DTLCP 三模式端到端仿真 + 防重放/篡改/重放攻击负向测试。
- **算力**：x86-64 实测 cycles（RDTSC+串行化）与 ns；REF vs OPT 同口径对比，给出加速比。
- **内存**：`size` 给出 text/data/bss；`-fstack-usage` 给出逐函数最大栈深；裁剪矩阵（功能开关组合）给出 Flash/RAM 差值。
- **功耗**：能量模型 E(op) = cycles × (V × I_dyn/MHz) / f，参数化（默认 V=3.0 V、100 µA/MHz、26 MHz，Cortex-M4 典型），输出 µJ/操作与"终端每日报文"场景能耗；**明确标注为模型估算**，接口预留实测参数替换。
- **协议开销**：三模式的 RTT 数、报文条数、线上字节数、SM2/SM3/SM4 调用次数、握手时延（本地 UDP 实测）。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| DTLCP 无公开全文标准，消息布局无法逐字节对齐 | 实现 **TLCP（GB/T 38636）语义 + DTLS 数据报机制**的兼容子集；docs/02 给出"与标准差异表"，字段布局按 TLCP 命名与类型保留 |
| 自研曲线算术有隐性错误 | REF/OPT 差分（万级随机）+ 标准向量 + OpenSSL SM2 交叉验证 + 曲线方程/阶自检 |
| 无 Cortex-M 硬件，无法实测 MCU 功耗 | host 实测 cycles + 指令级分析；功耗用**参数化能量模型**（标注估算）；交付 DWT 周期计数接口，板上可直接替换为实测 |
| 算法内核写错导致结论不可信 | 先 KAT 后优化；任何优化内核必须先过差分才进入基准 |
| Windows 无 make | 全部构建脚本化（bash + gcc），一键 `scripts/build.sh` |
